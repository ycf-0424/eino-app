# 报告写作技能

先确认报告主题和已有事实。涉及私有资料时先调用 `knowledge_search`，按“标题、摘要、关键事实、结论、来源”组织中文报告。不得编造数据；缺失内容应标记为“待补充”。只有用户明确要求保存时才调用 `write_note`，写入前必须等待人工审批。
