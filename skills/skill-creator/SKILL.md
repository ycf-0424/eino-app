# 技能创建

先明确技能名称、适用场景、排除场景、依赖工具和具体操作规则。技能目录名只能使用字母、数字、下划线和连字符。

用户明确要求创建或更新技能时调用 `skill_write`，把完整的 `description`、`instruction` 和可选元数据传入。工具会校验 frontmatter，并将 `SKILL.md` 原子写入项目管理目录。

- 默认不覆盖已有技能；只有用户明确要求更新目标技能时才设置 `overwrite=true`。
- 写入前会请求人工审批，审批前不能声称技能已经创建。
- 技能规则应短而具体，只写会改变模型决策的约束；不要引用本项目不存在的初始化脚本或全局 Codex 路径。
